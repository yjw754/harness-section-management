# 截面管理

## 1. 算法概述

截面管理算法是用来将不同半径的线缆，分布到一个有限的圆形范围内，用来处理过某一个点的多条线缆分布问题。
由于线缆一般情况下都是基于圆形截面的建模，所以截面管理问题也可以等价为基于不同半径的圆形几何紧凑分布问题。

圆形分布存在多种形式，目前有算法可以实现圆形基于某点的紧凑分布，基于一定范围内的分布等等。但是在问题研究时需要注意，不同的问题描述解决方案可能不适用线束中的分布问题。比较容易搜索到的是circle packing问题，这类问题是如何使用不同半径的圆形对目标进行填充，这个算法可以解决某些线缆固定器中线缆容量的问题，但是一般状态写的依附布线分布问题无法解决。另一类是基于circle packing问题的变形，去除了边界，通过动态迭代的方法，搜索符合目标的分布形态，这类算法更符合截面管理的需求。

但是自动分布或者迭代搜索的方法可能存在一个问题，就是用户通过相同的操作可能得到不同的结果，这个问题在这类优化问题中是可能出现的，所以未来如果实现类似方法，需要关注结果的稳定性。

## 2. 算法设计

### 2.1 单层截面管理
当前截面管理是自定义规则的方法设计的处理流程。
1. 获得所有截面半径，然后从大到小排序（A，B，C，...）。
2. 以最大线作为中心A。
3. 以A为中心，位置点中截面的X方向为基准，找到B与A外切的位置放置B，将B定义为尾部。
4. 计算放置位置方法举例，比如放置C的时候，需要基于A，B以及半径计算C放置的位置。
5. 放置时检查方法举例，比如放置D时，基于A以及C计算位置，然后使用中心A和尾部B计算是否放得下。
6. 如果A已经放不下了，则将中心定义为B，C定义为尾部，直到全部圆形分布结束。

以上方法可以保证生成的结果是稳定的，可以通过控制圆形半径排序方法，唯一确定一种分布方式。

实现：HrnCrossSectLayout.cpp， **HrnGetSection**  
输入：截面半径列表，截面ID列表  
输出：截面列表<截面半径，截面圆心位置，截面ID>

### 2.2 最小外接圆算法
在截面管理中，我们需要根据当前分布方式计算某段依附布线线缆的最小外接圆半径。这个半径可以作为未来添加bundle时的基础半径，比如使用胶带等基于厚度的材料。

外接圆的生成效果其实取决于分布算法，基于目前自定义规则方式生成的外接圆并不是最紧凑的半径最小的外接圆。

外接圆算法当前基于的方法是：[Approximating Smallest Enclosing Disks](./paper/Approximating_Smallest_Enclosing_Disks.pdf)。 

实现：HarnessAlg.cpp, **HrnGetDiskMinDisk**  
输入：截面列表  
输出：外接圆<外接圆半径，外接圆圆心位置>

### 2.3 多级嵌套截面管理
通过结合最小外接圆算法和单层截面管理算法，实现了多级嵌套截面管理算法。该算法的核心在于获取截面之间的嵌套、依附、连接等关系，构建截面的层次结构。首先，以自底向上的方式计算每一层截面的半径，同时记录该层与其父层之间的相对偏移量。然后，采用自顶向下的方式，逐层累加各层截面的偏移量，最终计算出整个截面的综合效果。

1. 根据输入的截面关系，构建一棵以截面为节点的树，并计算每个截面在树中的层级。
2. 对截面关系进行排序，使得低层级的截面排在前面，并确保具有相同父节点的截面彼此相邻。
3. 根据排序后的顺序，自底向上的计算每个截面的半径。通过材料特性和子节点的半径，计算当前节点的截面半径，并确定其相对于子节点的偏移量。
4. 根据反向顺序，自顶向下的计算二维偏移量。将父节点的偏移量累加到每个子节点上，根节点的偏移量视为0，直到算法执行完毕。

实现：HrnPosPntCrt.cpp, **HrnGetMultiSection**  
输入：截面ID列表，截面材料列表，截面关系  
输出：截面列表<截面ID, 截面半径，截面圆心位置>

## 3. 算法实现

### 3.1 代码实现
截面管理的接口实现在HrnPosPntCrt.cpp的函数 **HrnPosPntGenSegLoc** 中。

**HrnPospntGetHrnObjList**：获取截面ID，即位置点上需要计算截面信息的所有对象，包括线束对象与依附的中心线。

**HrnPospntGetRepObj**：整理截面ID。某些具有连接关系的线束对象具有相同截面，计算时取其中一个作为代表即可。

**HrnPospntGetObjRelation**：获取截面关系。根据线束对象的依附、分支、连接等关系获取截面之间的层级关系。

**HrnPospntGroupSingleObj/HrnPospntUniqueObjAndRel**：整理截面。为无依附或连接关系的线束对象创建默认的关系，选取它们当中的一个作为代表参与截面计算。

**HrnObjGetMaterialMap**：获取截面的半径信息，根据材料种类不同，半径可能是固定值，也可能是与子层级截面外接圆相关的变量。此信息可仅由线束对象的材料获取。

**HrnGetMultiSection**：多层嵌套截面管理函数。计算二维平面的截面管理。

**HrnPospntGet3DLoc**：根据位置点信息与二维偏移量，计算三维各线束对象真实的截面位置。

**HrnPospntSetSegLocAll**：将真实截面位置写入各个线束段。

**HrnPospntRevisePntOnExtend**：对端口延申直段上的位置点的特殊处理函数。

### 3.2 辅助函数
**HrnObjUpdRadByMtl**：根据线束对象内部子对象的外接圆半径与线束材料，计算该对象实际的半径。由于线束材料的半径不一定是定值，可能与内部对象外接圆相关，且编辑Echo流程中可能切换材料，需要此函数收集信息计算出真实的线束对象半径。

**HrnPospntCalSegOffset2D**：根据位置点中三维线束段截面位置，计算二维平面中对应的截面位置。用于预览时位置点修改位置方向，同步更新各线束对象的截面信息。

**HrnPospntCalSegLocByOffset2D**：根据位置，方向，二维截面位置计算三维截面位置。作用同上，用于预览时的实时显示。


### 3.3 算法补充应用
截面管理算法可以一并计算出线束对象的外接圆半径。因此在测量位置点直径命令、获取线束段半径等函数中同样应用了截面管理的流程。 

测量位置点直径：**HrnInqDiamCalDiam**。由于位置点存在线束段的正向与反向列表，参与计算的截面可能与截面管理不一致，其余流程与截面管理近似。

获取线束段半径：**HrnSegmentGetRadius**。获取线束段所属线束对象在该段的半径。广泛应用于生成线束Shell、Echo等显示流程中。

## 4. 总结与算法拓展
截面管理算法基于单层自定义截面管理算法、最小外接圆算法以及获取的截面关系，解决了截面的偏移量计算问题，实现对数据库对象的解耦，是一个纯内存计算流程。

算法设计中，单层截面管理算法与截面的层级嵌套彼此独立，具有可替换性。这意味着在实际应用中，可以根据需求选择不同的单层算法实现截面效果，如在排线需求中使用了矩形的排布算法，实现了排线效果，灵活适应需求。

但是，目前的设计无法为每一层的截面指定自定义的截面效果，原因是计算完成后，承载截面管理的位置点不存在足够的数据位记录截面的层次信息，不支持为每一层定义特定效果。未来视需求决定是否需要处理。

最后，在某些特定边界条件下，现有算法的视觉效果不佳。例如相同线束在位置点的两侧均存在线束段，却属于不同的层级，造成算法无法处理这些跨层的情况，只能以默认位置处理。如何检测出实际布线中不合法的嵌套关系，或尽可能优化不合法情况的视觉效果，未来需要进一步完善以适应极端情景。
