# 待办清单

## 低优先级：相同半径截面的输入顺序无关排布

- 现状：规则布局按半径降序稳定排序；半径相同时沿用本侧 Section 的输入顺序。同一输入重复求解稳定，但交换添加顺序可能改变圆心。
- 目标：为每个侧内 Section 建立持久且唯一的身份键，并在相同半径时以该键决定规范顺序，使添加顺序变化不改变同一组 Section 的排布结果。
- 身份方案待定：若已有持久 Segment UID，优先使用 `(Side, Segment UID)` 作为侧内 Section 键；只有 Section 需要独立于 Segment 延续身份时，才考虑单独的 Section UID。克隆、编辑、序列化和重新求解须保留身份，新增对象须获得新 UID。
- 实施范围：除半径排序外，还要检查子节点遍历、候选同分决胜、跨侧同位置组的遍历与修复顺序；统一使用规范键。新增“同一组 UID、不同添加顺序”的双侧嵌套回归测试，并验证圆心、半径及诊断结果的一致性。
- 边界：UID 本身不会自动改变现有排布；需要把规范键用于求解器所有会影响决策的顺序。保持相同输入重复求解的既有稳定性。
