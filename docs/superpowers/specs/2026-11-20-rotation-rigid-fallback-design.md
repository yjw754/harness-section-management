# 圆形截面旋转兜底

对已成功排布的 Stage 2 圆形案例，仅编辑有效的旋转角时，优先使用现有局部旋转、同位置联动和冲突修复。局部方案无法满足约束时，正负侧沿 Position Point 同一基准，以共同原点为轴心，按本次编辑的角度差对上次成功布局做整体刚体旋转。

只重排局部候选不能保证成功：例如关联圆必须保留在一个不可移动的约束位置。每次都整体旋转则会不必要地改变无关截面。本方案只在局部失败时整体转动；整体旋转保持同位置类、包含、半径、间距和正负侧之间的相对几何。

面板保留用户输入的各个局部角度，诊断标明是否用了整体旋转，结果视图展示实际的全局角度。下一次局部编辑以已旋转后的布局为起点，以输入角的变化量控制局部旋转；不重新计算或清除整体旋转的效果。多个编辑合并求解时，最后一次仍有效的角度变动决定整体旋转步长。

局部排布在未转动的参考坐标中校验，再将累积整体角度应用到输出。整体兜底只复用求解器生成的已求解快照；调试器核对成员 ID 和顺序，内核核对当前变换、层级、映射、尺寸和排布参数。WASM 旋转入口只接受这种快照。不对刚体变换后的坐标进行二次碰撞判定，避免将舍入误差带回求解。中途修改又撤回的字段不影响判断。原生调用传入的裸坐标不具有快照资格，仍须通过几何校验。

不改变 JSON v1，不为尚未求解或同时修改尺寸、拓扑、映射的草稿承诺成功，不扩展到非圆形。保留不合法输入、不可变边界及正常求解的诊断。只有有效侧 Root 参与布局；单顶层时仍以成员截面为根。
