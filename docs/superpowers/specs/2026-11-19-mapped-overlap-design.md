# 映射导致的同侧重叠

用户要求：支持 `N_1.json` 中两条跨侧同位置映射导致的正侧同级截面重叠，并增加案例。

显式 `samePosition: true` 边的传递闭包定义共享圆心的等价类。同侧同级成员属于同一等价类时，允许同心重叠并豁免彼此间距要求；成员仍保留独立身份、半径、层级和映射。普通对应不合并等价类，不同类继续检查间距和干涉。父子包含与父边界间距始终有效。

采用同一份等价类数据同时驱动初始层级排布和联合求解：一个父级下的同类成员以最大成员半径作为单个占位圆，放置后恢复每个成员。联合求解和独立最终校验仅豁免同类兄弟的相互干涉。仅跳过最后报错会在固定边界中提前失败；全面允许兄弟重叠又会掩盖普通干涉，均不采用。

验证涵盖原始 2 对 1、镜像 1 对 2、不同半径、固定/自动 Root、嵌套兄弟、传递闭包、普通映射隔离、父子越界和事务回滚。增加可导入 JSON 与浏览器/WASM 回归，更新原先把此类重叠认定为失败的验收案例和文档。
