# 映射固定圆心后的规则重排

用户反馈 `deranged.json` 正侧排布不规则且不紧凑。复现表明映射重定位后只做逐对碰撞推开，大圆中心约为 (-4.4485,-8.9831)，相对固定侧 Root 原点占用半径约 18.02，小圆群与大圆脱离。

采用带固定圆心的规则重排：将同位置映射及映射子树视为固定障碍，其余兄弟按半径递减顺序，枚举双圆相切交点和单圆相切方向。优先减少原点包络半径，同包络候选优先靠近父中心，以稳定顺序破平局。固定父边界过滤不可容纳候选。成员移动时整棵无映射子树一起移动，保留层级、半径和用户旋转。

只对映射实际移动了固定成员、且同时存在自由成员的父级尝试一次重排；若候选无法完成则保留原状态，沿用现有修复和诊断。原始无约束规则排布、单截面跟随和同位置组重叠语义继续有效。组内兄弟以最大半径形成一个占位，组外保持间距。正负方向对称，局部候选坐标遵守父级累计旋转。

不采用全局连续优化：本次沿用确定性相切候选以保持可解释性、重复性和有限计算量。也不只平移现有布局：那不能消除大圆与小圆群之间的空隙。

验证原始案例及正负镜像，要求大圆与两个映射小圆均相切、正侧占用半径不超过 15（原约18.02）、自由小圆与至少一个其他圆相切、所有包含和间距有效。补充固定圆心低层求解、边界限制、间距和重复性测试，保留七个无约束参考向量。
